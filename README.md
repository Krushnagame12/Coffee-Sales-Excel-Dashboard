Coffee Sales Dashboard

An Excel-based sales analytics dashboard for a coffee business, tracking orders, revenue, product performance, and customer insights across multiple countries from 2019 to 2022.

 Dashboard Overview
The Coffee_Sales_Dashboard.xlsx contains the following sheets:

Dashboard — Main visual overview of sales performance
TotalSales — Monthly sales breakdown by coffee type (2019–2022)
CountryBarChart — Total sales by country
Top5Customers — Top 5 customers ranked by total spend
orders — Full order-level transaction data
products — Product catalog with pricing and profit margins
